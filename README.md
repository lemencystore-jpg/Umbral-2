# Umbral — Ecos de un mundo olvidado

Juego 2D (HTML5) empaquetado como APK con Capacitor y GitHub Actions.

1. Sube estos archivos a un repositorio de GitHub (rama main).
2. Ve a Actions → "Build APK" → Run workflow (se ejecuta solo en cada push).
3. Al terminar, descarga `Umbral-apk` desde Artifacts, descomprime e instala `Umbral.apk`.
4. Para un release con el APK adjunto: crea un tag `v1.0.0`.

Para editar el juego, cambia `www/index.html`.

Novedades: historia con cinemáticas y sonidos (inicio, zonas, jefes y final), golpes con enfriamiento anti-spam, soporte de mandos (estándar y genéricos, cruceta/hat, vibración).
Mando: A saltar · X/LB atacar · B/RB/RT dash · Y/LT Aster · Start pausa.
